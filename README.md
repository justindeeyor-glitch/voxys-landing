# VOXYS — лендинг

Статический одностраничник, свёрстанный по макету Figma «Lifecircle».

## Стек

Чистый HTML + CSS. Ни сборщика, ни зависимостей, ни JavaScript.

- `index.html` — разметка
- `assets/style.css` — стили
- `assets/img`, `assets/svg` — графика, выгруженная из макета (WebP, 812 КБ)

Шрифт — [Golos Text](https://fonts.google.com/specimen/Golos+Text) с Google Fonts.

## Адаптив

Четыре опорные ширины из макета: **360 / 768 / 1024 / 1440**. Между ними
раскладка резиновая — высоты, отступы и кегли интерполируются через
`calc()` от `100vw`, поэтому на промежуточных ширинах ничего не прыгает,
а на опорных попадает в макет точно.

| Ширина | Высота страницы | Макет |
|-------:|----------------:|------:|
| 1440 | 6030 | 6029.89 |
| 1024 | 5315 | 5314.77 |
| 768 | 6441 | 6441.14 |
| 360 | 6889 | 6889.16 |

## Появление при скролле

Элементы проявляются по мере входа в экран. Ведёт это `assets/reveal.js`
(90 строк, без зависимостей) через `IntersectionObserver` — он работает
одинаково во всех браузерах, в отличие от CSS-шкал прокрутки, которых
пока нет в Firefox.

Анимируются только `opacity` и отдельное свойство `translate`. Отдельное —
намеренно: у центра схемы жизненного цикла и у блока с QR-кодом `transform`
уже занят позиционированием, а `translate` складывается с ним, а не затирает.
Раскладка при этом не смещается ни на пиксель.

### Три вещи, без которых это ломается

**Скрытое состояние появляется только вместе с классом `.js-reveal`,**
который ставит крошечный скрипт в `<head>` — до первой отрисовки, иначе
элементы мелькнут видимыми и только потом спрячутся. Если JavaScript
отключён, не загрузился или в системе включено «уменьшить движение»,
класса нет: страница просто статична и полностью видна. Невидимым
контент не остаётся никогда — проверено рендером с выключенным JS.

**Одного `IntersectionObserver` мало.** Он сообщает только о смене
состояния: если при резкой прокрутке элемент пролетает экран за один
кадр, порог не пересекается, события нет — и элемент остаётся скрытым
навсегда. Поэтому на каждый кадр прокрутки оставшиеся элементы
досматриваются вручную. Проверено на прыжке в конец страницы, на
End/Home и на прокрутке шагами по 2000 пикселей.

**Обрезка задана через `overflow: clip`, а не `hidden`.** Это осталось
от предыдущей, чисто CSS-реализации, но менять обратно незачем: `hidden`
делает элемент контейнером прокрутки со всеми побочными эффектами, а
`clip` режет так же и без них. По той же причине на `body` нет
`overflow-x: hidden` — вместо маскировки горизонтального вылета стоят
настоящие ограничители ширины.

## Отступления от макета

Три места, где макет сам себе противоречит — решения приняты заказчиком:

1. **Секция «Помогаем управлять» на 360.** В макете там осталась десктопная
   схема шириной 750px, обрезанная по 360: центральная картинка и вся правая
   колонка за кадром. Раскладка сохранена как есть, секция скроллится вбок —
   ничего не выдумано и ничего не потеряно.
2. **Секция «3 слоя продуктовой архитектуры» ниже 1024.** Макет оставляет
   только колонку направлений; 8 этапов цикла и 11 продуктов отсутствуют,
   хотя вводный текст описывает все три слоя. Воспроизведено как в макете.
3. **Секция «Нам доверяют»** отсутствует во фрейме 360 — скрыта ниже 768.
